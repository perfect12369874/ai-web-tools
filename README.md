# 橡皮擦合成

免费在线小工具，服务 AI 影视圈。**纯前端**：图片不上传，全部在你自己的浏览器里处理。

- 在线版：<https://taozui.name/tools/eraser/>，打开即用
- 本地版：页面右下角下载 zip，解压后双击 `index.html` 即可离线使用，功能完全一样

## 它做什么

PS 里「原图在上、修改图在下、降低不透明度看重影、橡皮擦擦掉原图露出修改」的那套操作，压成一个页面：

1. 拖入原图和修改后的图（两个拖放框，或两张一起拖，拖错点 ⇄ 交换）
2. 自动对齐：金字塔梯度匹配找全局平移，再分块测局部位移、最小二乘拟合「平移 + 轻微缩放」，亚像素精度
3. 自动校色：用两图中没变化的像素统计修改图的偏色，反向校正
4. 改动候选：在 1/2 尺度上算两种差异，各自按噪声阈值（中位数 + 8×MAD，排除 2% 边缘）归一化后取大者：「窗口平均色之差」抵消重渲染的纹理位移、能抓到指针这类细线的颜色变化；「逐像素差的窗口平均」填满纹理变了但平均色没变的区域。超过阈值的像素连成区域，按差异总量排名，大块相邻的合并。第一名强度是第二名 20 倍以上且面积够大，就自动擦出并标红；否则把前五名用虚线框标在画面上，框上带「擦掉」按钮
5. 手擦模式：原图不透明度默认 100%，拉低能看到重影，重影处即改动。画笔「修改」涂到哪里哪里换成修改图，「还原」还原成原图，「按住对比」看前后（对比时候选框和提示会隐藏）。缩略图悬停 × 可移除重选
6. 下载合成图：原尺寸 PNG，蒙版之外与原图逐像素一致。「下载 PSD」导出三层文件

界面没有顶栏：画布在上，底部两行居中。第一行是原图和修改图两个素材槽（空槽是 + 号加名字，放入后只显示按原图比例的缩略图，点击可更换，悬停 × 移除，中间 ⇄ 交换）；第二行是工具：画笔模式 修改/还原、修改范围、画笔组（实心/柔边 + 大小滑块 + 预览点）、原图不透明度、按住对比、下载合成图、下载 PSD。撤销用 ⌘Z，快捷键面板在右下角。对齐微调、校色参数、柔边、重新识别、PSD 导出、处理状态全部收在「高级」弹层里。

## 自动识别改动区域：能做到什么，做不到什么

目标是用户只上传原图和修改图，工具自动找到改动、自动合成，省掉手擦。在一张真实图对（摩托车 POV，AI 只改了仪表盘、但整张图被重新渲染）上实测过这些方法：

| 方法 | 结果 | 结论 |
|---|---|---|
| 像素差异（模糊 + 局部均值） | 仪表盘均值 10.8，全图 5% 区域超过 16 | 失败，重渲染噪声比改动大 |
| DINOv2 语义特征块相似度 | 最好的组合（vits14 第 6 层 + 平滑）仍有 4.7% 的其他区域高于仪表盘 | 失败，细微原位改动是文献公认的失败情形 |
| 语义 × 像素 相乘 | 更差（18% 到 27%） | 失败 |
| CLIPSeg，文字 "speedometer" | 原图 IoU 0.64 | 可行但粗糙 |
| GroundingDINO-tiny + SAM-base，文字 "speedometer" | 框 IoU 0.67，SAM 蒙版精确贴合表盘 | 可行，但需要告诉工具改了什么 |

结论：不给任何提示、纯靠两张图比较，对整图重渲染类工具的输出做不到可靠自动识别；这是"比较像素"和"理解画面"的本质差别。所以工具的策略是：**改动够大就全自动，细微改动给出候选、手擦兜底。**

三组真实图对的实测（当前版本的检测器）：

| 图对 | 改动 | 第一/第二强度比 | 工具行为 | 结果 |
|---|---|---|---|---|
| 马克杯 | 杯身咖啡渍图案去掉，杯口咖啡去掉 | 211 | 自动擦第一名 | 正确，蒙版盖住杯身，把手和手不受影响 |
| 包装小字 | 一行小字"醇厚"改"顺滑" | 14 | 标出候选 | 第一名是整块标签区域（含小字），点击可擦整块 |
| 仪表盘 | 表盘换款、指针位置变了、加本田标 | 1.8 | 标出 5 处候选 | 本田标第 2、指针第 4，底部两处也是真实的重渲染差异；表盘面其余部分需手擦 |
| 合成测试图 | 替换一块区域 | 37 | 自动擦第一名 | 正确 |
| 办公室去人物 | 去掉 8 个人（6336×2688） | 27 | 自动采用 5 处 | 站着的三人 + 坐着的三人 + 贴右边缘的人 + 一条腿全部覆盖；沙发、绿植、显示器不受影响 |
| 换背景 | 人物不动，整个环境换掉（6376×2699） | 不适用 | 背景替换模式 | 36% 像素变了；保留五个人 + 桌面（一块连通前景），其余换成修改图 |

规律：改动够大（占画面 2% 以上、强度远高于重渲染噪声）就能全自动；细微原位改动只能给出候选提示。分析代码在 `analyzeChanges()`。

## 验证记录

合成图对（Higgsfield 出图 2752×1536，人为加 R+5 B+6 偏色、暗部压暗、右侧替换一块内容、整体平移 (+5, −3)）：

- 自动对齐找回 x +5 / y −3，AI 图缩到一半尺寸再载入仍然正确
- 自动校色采样 99% 未变化像素，偏色读数和设定一致
- 替换区域被自动擦出，不用手擦
- 导出 PNG 在蒙版之外与原图逐像素相同（最大差值 0）
- PSD 用 psd-tools 独立解析：三层齐全，蒙版满尺寸、边缘精确，PSD 合成与 PNG 逐像素一致

真实图对（摩托车 POV 1152×2048，AI 只改了仪表盘，但整张图被重新渲染，带约 0.3% 横向、0.7% 纵向的缩放）：

- 纯平移对齐在仪表盘处会差 2 到 3 px，升级成「平移 + 缩放」后残余错位 0 px
- 自动校色：修改图偏色 R +1.9 G +1.4 B +4.1，采样 95% 像素
- 自动识别判定"差异遍布全图"，正确地落回手擦；手擦三笔（200px 画笔、硬度 50%）后导出，蒙版外与原图逐像素相同

尚未在 Safari 实测（只在 Chromium 里跑过）。

## 技术

- 单文件 HTML，无构建步骤，Canvas 2D；PSD 写出用 `eraser/vendor/ag-psd.js`（v31.0.2，MIT），仅在导出 PSD 时按需加载
- 调试入口：`?orig=<url>&ai=<url>` 自动载入（仅 http 下），`?debug` 显示高级面板，`window.__eraser` 暴露内部状态
- 本地预览：任意静态服务器即可，例如 `python3 -m http.server 8000` 后打开 `http://localhost:8000/eraser/`；或直接双击 `eraser/index.html`
